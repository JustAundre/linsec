# Contributing

Before making a bug report, feature or pull request, please check the following:

- Vow(s) of competence:
  - [ ] I am running the latest version of the scripts.
  - [ ] I uploaded the relevant terminal output and log files.
  - [ ] I have read the README and made an attempt to look for duplicate reports.
- Vow(s) of honor:
  - [ ] I didn't ask big AI to find bugs for me.
  - [ ] (Even if?) I used AI, I can comprehend and vouch for the quality of its work.
  - [ ] I dedicate my contribution to the license of this repository (*the MIT license*).
